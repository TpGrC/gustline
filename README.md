# Gustline

Global weather map by Halewood Systems. Wind, gusts, temperature, rain, clouds, pressure, humidity, thunderstorms and snow, with a 10-day timeline.

- Map data: NOAA GFS 0.5° model, downloaded and processed automatically every 6 hours by GitHub Actions.
- Point forecasts and place search: Open-Meteo.
- Map: Leaflet with Esri basemaps.
